## 2026-11-08 — Assumptions made while building Stage 1 (owner to confirm)

- Blocking a doctor stops only the doctor; their patients can still log in and see reviewed results.
- A device can only be assigned to an active doctor. A device keeps finishing an exam it already started even if
  it is re-assigned meanwhile.
- No limit on queued exams per device: commands run oldest first. No timeout for an exam stuck in `recording`
  (device took the command but never uploaded) — the doctor starts a new exam.
- Another doctor's patient/exam/device answers 404 (not 403), so ids of others are not revealed.
- Patients see: date, chest point, doctor's note. Not the AI label/score and not "doctor agrees with AI".
- Admin stats "today" = calendar day in Asia/Tashkent (`APP_TIMEZONE`).

## 2026-11-08 — Windows Smart App Control workaround
